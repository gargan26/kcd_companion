# 天国助手使用指南

## 面板

在同一台电脑的浏览器里打开 `http://127.0.0.1:17603`（天国2助手用的是 17602）。面板由插件提供。共有九个页面：

| 页面 | 内容 |
|---|---|
| **任务** | 所有已开始的任务及其进行中的目标，目标显示为游戏语言下的日志条目；任务内部用来记录状态的隐藏目标（监视某人是否死亡、某个标记）不列出。每个目标有**推进**（Quest Autopilot 的 `st_advance`：前置条件未满足时不执行，并说明缺的是哪一个），不执行时还有**强制**。两者都按游戏自己的方式完成目标：对话原本会交出或拿走的物品照样交出或拿走，对话原本会开始的目标照样开始，游戏在等的物品会直接给你。如果游戏在那一刻做的比助手能做的更多（一段过场、某人离开、声望变化），按钮显示为**推进（有风险）**，提示里写明会漏掉什么，按下前先询问（勾选*不再提醒*即关闭询问；在“杂项”里打开*跳过可能让任务卡住时先提醒*可再打开）。游戏自己从不完成的目标没有按钮。每个任务有**前往**（去当前目标，位置与 `st_goto` 找到的一致）；Quest Autopilot 有抉择数据的任务还有**跳到下一个抉择**（`st_skip`）；结局目录里收录了结局的任务还有**最佳结局**和**最差结局**（`st_good`、`st_bad`；遇到第一个有风险的步骤就停下）；任务相关的人物也列在下面，可以前往和召唤。选项：*全部目标*（每个目标附上状态，隐藏目标带标记，并列出它会开启哪些目标）、*结局*（结局目录里的每个结局，各有*以此结局完成*）、*已完成的任务* |
| **自身** | 亨利的状态（生命值、耐力、营养、能量：+10 或回满，以及*全部回满*）、金钱（格罗申 −100 / +100 / +1,000 / +10,000）、四项属性和游戏显示的十八项技能，每项都有 +1 / +5 / 满级（20），名称取自游戏自带的文本。升级的方式是加经验，每次加的经验不超过升一级所需的最少经验，直到显示的等级达到目标，所以临时加成不会让等级升过头；游戏不会降回已有的等级，所以等级没有减号按钮 |
| **地点** | 村庄、城镇、修道院、旅店和林地，由近到远排列；展开后是那里的商店、炼金台、磨刀石、澡堂，以及能睡觉的床（旅店床铺、自己的床），每一项都能前往。有快速旅行点的城镇或村庄，落点就在快速旅行点，与游戏自带的快速旅行相同；其余地点落在地点的中间。*所有床铺*会加上 1,988 张普通的床。**标记此处** / **返回**。在 **X**、**Y** 里输入坐标后按**前往**（或在任一格里按回车），会落到那一点能站的地方，步行、骑马都行（房屋里落在地板上而不是屋顶，岩石落在顶上，桥上落在桥面，河里落在水面）；状态行显示你所在的位置（`你在 2491, 1260`），现在记下的地方，以后可以再输回去。不在地图上的点（X、Y 都在 0 到 4096 之间），或那里没有可站立的地面，会给出提示，不传送。视图：*只看商店*、*只看工作台、澡堂和床铺* |
| **人物** | 游戏世界里已载入的所有人，按游戏内名字显示，由近到远（显示 150 个，*全部显示*可看其余），可以前往和召唤；*50 米以内* |
| **物品** | 全部 2,052 件物品，按逛商店的思路排列：上方是类别栏（武器、护甲与衣物、战马、食物与饮品、药剂、草药与炼金、书籍与地图、工具、钥匙、骰子、其他），每个类别再按玩家找东西的方式分组（剑、马刀、长剑……箭；头部、躯干、手臂、手部、腿部、脚部，从头盔到靴子；治疗、增益、毒药；技能书按技能和所需等级；钥匙按村镇和房屋编号），组内最好的排在前面，名称旁边列出物品栏里显示的数值（刺击、劈砍、钝击、防御、力量、噪音、魅力、营养、能量、酒、最小力量、价格）。看起来完全相同的几件合并为一行。较长的组先显示 120 件，**全部显示**可看其余。输入名称（游戏语言或英文）或 ID 会在所有类别中搜索。**获取**可指定数量；**前往**带你去能弄到它的地方，每按一次去下一处，由近到远：出售它的商店、存放它的容器、它摆放的位置（`商店：面包师（第 1 处，共 9 处）`，英文界面为 `shop: Baker (1 of 9)`）。视图：*有获取地点*、*任务物品*、*物品栏里有*（后两项在所有类别中搜索）、*按名称排序* |
| **箱子** | 当前地图上的所有容器（箱子、麻袋、架子、坟墓、鸟巢、尸体），由近到远，已上锁的有标记，鼠标悬停可看到里面的物品来自哪个战利品表；可以前往。视图：*只看上锁的*、*只看没上锁的*、*有战利品表的* |
| **成就** | Steam 上的 82 个成就，分为*尚未获得*和*已获得*（附获得日期），名称和说明取自 Steam，并注明由哪个任务给予，或靠哪项计数达成。**解锁**会在你的 Steam 账户上设置并保存一个尚未获得的成就；解锁后 Steam 会一直保留，修改器无法撤销 |
| **指南** | 这份指南（游戏为中文时显示中文版）和 `findings.md`，在窗口里直接阅读 |
| **杂项** | **立即存档**（不用喝保存药剂）、**召唤我的马**、**返回**；**作弊模式**，每项可开可关：*无敌模式*（不会死亡，生命值自动回满）、*无限耐力*、*不饿不累*、*隐身无声*、*双倍移动速度*、*双倍伤害*、*大幅提高负重*、*三倍经验*。回满类效果由模组自己每秒一次的刷新执行；其余是模组自带的常驻增益（`src/Libs/Tables/rpg/buff__questautopilot.xml`），读档时游戏会清掉它们，刷新时会再加上。游戏选项：*“跳到下一个抉择”停下后把你传送到停下的地方*（默认开）、*每次传送都带上你的马*（默认关） |

带筛选框的列表在游戏端筛选，物品搜索因此覆盖全部 2,052 件物品。天国2助手的*装备不磨损*在一代没有对应功能：一代的 Lua 拿到的只是物品耐久的副本，没有任何调用能把改动写回去。

## 语言

修改器跟随游戏的文字语言（`g_language`）。人物、地点、物品、任务的名字和日志条目，都按文本键从游戏自带的文本表里读取，与游戏里显示的一致。修改器自己的文字是英文；游戏使用简体中文时则显示中文。成就名称来自 Steam，使用 Steam 的语言。F6 窗口在每次启动游戏后第一次打开时读取语言。在游戏设置里换了语言，要重启游戏，窗口的标题和页面名才会跟着换。

## 在游戏里

| 按键 | 作用 |
|---|---|
| **F6** | 打开或关闭修改器窗口：面板的九个页面，直接画在游戏画面上。窗口打开时，游戏收不到键盘和鼠标输入：在筛选框里打字不会让角色走动，点击也不会挥剑 |
| **F8** | 前往日志里最后选中的任务的当前目标（`st_tracker` 跟随日志里的选择；还没选过任务时，用第一个激活的任务） |
| **Esc** | 窗口打开时关闭窗口（游戏收不到这次 Esc） |
