# KCD Companion — user guide

## The panel

`http://127.0.0.1:17603` in a browser on the same PC (KCD2 Companion is on 17602). The plugin serves it. Nine tabs:

| Tab | What's in it |
|---|---|
| **Quests** | every started quest with its current objectives, by their journal lines in the game's language; hidden bookkeeping objectives (a watcher for someone's death, a flag) are left out. Per objective **Advance** (Quest Autopilot's `st_advance`: refuses when a prerequisite is unmet and says which), **Force** where it refuses. Both complete the objective the way the game does: they hand over or take the items the conversation would, start what it starts, or give you the items the game is waiting for. Where the game does more at that moment than the trainer can (a scene, a person walking off, a reputation change), the button reads **Advance (risky)**, its tip says what is missed, and it asks first (*Don't remind me again* turns that off; Misc → *Warn before a skip that can leave a quest stuck* turns it back on). Objectives the game never completes itself have no button. Per quest **Go** (to the current objective, as `st_goto` finds it), **Skip to next decision** on the quests Quest Autopilot has decision data for (`st_skip`), **Best ending** and **Worst ending** where the ending catalogue has them (`st_good`, `st_bad`; a run stops at the first risky step), and the quest's people with Go and Summon. Options: *Every objective* (each with its state, hidden ones tagged, and what it unlocks), *Endings* (every catalogued ending with *Finish this way*), *Finished quests* |
| **Me** | Henry's condition (health, stamina, nourishment, energy: +10 or Fill, and *Fill all*), groschen (−100 / +100 / +1,000 / +10,000), the four stats and the eighteen skills the game shows, each +1 / +5 / Max (20), named in the game's own text. Levels rise by adding experience in steps no larger than the cheapest level until the level shown reaches the target, so a temporary bonus never makes it overshoot; the game never takes a level back, so there are no minus buttons on levels |
| **Places** | villages, towns, the monastery, inns and woods, nearest first, each opening onto its shops, alchemy tables, grindstones, bathhouses and the beds you can sleep in (an inn bed, your own), with Go on each. A town or village with a fast-travel point lands there, where the game's own fast travel lands; the rest at the middle of the place. *Every bed* adds the 1,988 ordinary beds. **Mark here** / **Back**. **X** and **Y** with **Go** (or Enter in either box) land you where one can stand at the point you type, on foot or on horseback (the floor inside a house rather than its roof, a rock's top, a bridge's deck, the water's surface on a river); the status line shows where you stand (`you are at 2491, 1260`), so a spot read now can be typed back later. A point off the map (X and Y each run from 0 to 4096) or with no ground under it gets a message and no jump. Views: *Shops only*, *Benches, baths and beds only* |
| **People** | everyone loaded in the world by their in-game name, nearest first (150 shown, *Show all* for the rest), with Go and Summon; *Within 50 m* |
| **Items** | all 2,052 items, laid out the way one shops: a category bar (Weapons, Armour and clothing, Horse, Food and drink, Potions, Herbs and alchemy, Books and maps, Tools, Keys, Dice, Other), each category in the groups a player looks for (swords, sabres, longswords … arrows; head, body, arms, hands, legs, feet, from helmets to boots; healing, boosts, poisons; skill books by skill and level; keys by village and house number), best first inside a group, and beside each name the numbers the inventory shows (stab, slash, blunt, defence, power, noise, charisma, nourishment, energy, alcohol, strength needed, price in groschen). Copies that read the same fold into one row. Long groups show 120 with **Show all**. Typing a name (in the game's language or English) or an id searches every category. **Give** with a quantity, and **Go** where one can be had: each press goes to the next place nearest first, a shop that sells it, a stash that holds it, a spot it lies on (`shop: Baker (1 of 9)`). Views: *Can be had somewhere*, *Quest items*, *In my bag* (these two search every category), *A to Z* |
| **Chests** | every stash in the loaded level (chests, sacks, shelves, graves, nests, bodies), nearest first, locked ones tagged, with what it is stocked from on hover; Go. Views: *Locked only*, *Unlocked only*, *Stocked with loot* |
| **Achievements** | Steam's 82: *Not yet earned* and *Earned* (with the date), named and described by Steam, with the quest that grants each one or the counter that earns it. **Unlock** sets an unearned one on your Steam account and stores it; Steam keeps it for good, and the trainer cannot take one back |
| **Guides** | this guide (in Chinese when the game is) and `findings.md`, read in the window |
| **Misc** | **Save now** (no Saviour Schnapps), **Bring my horse**, **Back**; **cheat modes**, each on or off: *God mode* (nothing kills you, health refills), *Infinite stamina*, *Never hungry or tired*, *Unseen and unheard*, *Run twice as fast*, *Hit twice as hard*, *Carry far more*, *Learn three times as fast*. The refills run on the mod's own once-a-second tick; the rest are the mod's own constant buffs (`src/Libs/Tables/rpg/buff__questautopilot.xml`), which the game drops at a load, so the tick adds them again. Play options: *Skip to next decision takes you to where it stopped* (on), *Every jump brings your horse along* (off) |

Lists with a filter box filter on the game side, so the Items search covers all 2,052 items. KCD2 Companion's *Gear never wears* has no KCD1 counterpart: KCD1's Lua gets a copy of an item's condition, and no call writes it back.

## Language

The trainer follows the game's text language (`g_language`). Names of people, places, items, quests and journal lines are read by key from the game's own text tables, so they match what the game shows. The trainer's own words are English, or Chinese when the game runs in Simplified Chinese. Achievement names come from Steam, in Steam's language. The F6 window reads the language when it first opens in a session; after a switch in the game's settings, restart for its title and tab names.

## In the game

| Key | Does |
|---|---|
| **F6** | show/hide the trainer window, the panel's nine tabs drawn into the game; the game is blind to keyboard and mouse while it is up, so typing in a filter walks nowhere and a click swings no sword |
| **F8** | go to the current objective of the quest last picked in the journal (`st_tracker` follows the journal's selection; before any pick, the first activated quest) |
| **Esc** | closes the window when it is open (the game does not see that Esc) |
